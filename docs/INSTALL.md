# تثبيت Spir-Margin على حاسوب الشركة

يتكوّن التثبيت من نصفين، ولكلٍّ منهما دوره:

1. **تشغيل البرنامج مع إقلاع الحاسوب** — حتى يكون النظام جاهزاً دائماً.
2. **تثبيت التطبيق من الإعدادات** — ليصبح له نافذته وأيقونته بدل تبويب متصفّح.

النصف الثاني وحده لا يكفي: الأيقونة تفتح نافذة تشير إلى البرنامج، فإن لم يكن
مُشغَّلاً فُتحت فارغة. لذلك نبدأ بالأول.

---

## 1) تشغيل البرنامج مع الإقلاع

ابنِ النسخة مرّة واحدة أولاً:

```bash
npm ci
npm run build
```

### لينكس (systemd)

```bash
sudo ./scripts/service/install-linux.sh              # المنفذ 3000
sudo PORT=8080 ./scripts/service/install-linux.sh    # منفذ آخر
```

يقرأ السكربت المتغيّرات المضبوطة عندك (`AUTH_SECRET`، `DATABASE_URL`، …)
ويمرّرها إلى الخدمة، لأن الخدمة لا ترث بيئة الطرفية.

للتحقّق أو الإيقاف:

```bash
systemctl status spir-margin
journalctl -u spir-margin -f
sudo systemctl disable --now spir-margin
```

### ويندوز

```powershell
powershell -ExecutionPolicy Bypass -File scripts\service\install-windows.ps1
```

يسجّل مهمّة تعمل عند تسجيل الدخول. لإزالتها:

```powershell
schtasks /Delete /TN "Spir-Margin" /F
```

### تحقّق

افتح `http://localhost:3000` — يجب أن تظهر شاشة الترحيب. أعد تشغيل الحاسوب
وافتح العنوان نفسه: إن ظهرت الشاشة فالنصف الأول تمّ.

---

## 2) تثبيت التطبيق

افتح **الإعدادات ← التثبيت كتطبيق** واضغط **تثبيت التطبيق**.

يظهر الزرّ في المتصفّحات المبنيّة على Chromium (Chrome، Edge، Brave). أما
Firefox وSafari فلا توفّر تثبيتاً بنقرة واحدة — استخدم قائمة المتصفّح نفسه
(«تثبيت» أو «إضافة إلى الشاشة الرئيسية»)، وتقول الصفحة ذلك بدل عرض زرّ لا يعمل.

بعد التثبيت يصبح لـ Spir-Margin أيقونة تفتحه في نافذة مستقلة.

---

## ماذا يعني هذا فعلاً

| يفعل | لا يفعل |
| --- | --- |
| نافذة وأيقونة مستقلّتان | لا يجعل التطبيق يعمل بلا البرنامج المشغَّل على هذا الحاسوب |
| يفتح من الحاسوب كأي برنامج | لا ينسخ البيانات إلى مكان آخر |
| يعمل بلا إنترنت | لا يغني عن النسخ الاحتياطي |

البيانات تبقى في قاعدة البيانات المدمجة داخل مجلّد التطبيق. بلا قاعدة
مستضافة مضبوطة، هذا المجلّد هو النسخة الوحيدة — خذ نسخة احتياطية من
**الإعدادات ← النسخ الاحتياطي والاستعادة**، واحفظها خارج هذا الحاسوب.
